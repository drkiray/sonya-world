# Письма дяде Ярику по почте

Соня отправляет текст из существующего окна письма одной кнопкой, оставаясь в игре. GitHub Pages и URL игры остаются прежними, чтобы IndexedDB на её телефоне сохранился.

## Доставка

- Форма Formspree принимает письмо по HTTPS и направляет его на адрес, заданный взрослым в панели Formspree. Адрес получателя и почтовые ключи не входят в клиентский код.
- ID формы задаётся при сборке через `VITE_LETTER_FORM_ID` (GitHub Actions variable). Без ID игра не отправляет письмо и показывает понятную ошибку.
- Перед отправкой проверяем непустой текст; ограничиваем длину до 2000 символов. Запрос отправляет только текст письма и заголовок, без фотографий и игровых данных.
- Успешный ответ означает, что сервис принял письмо. После него обновляются локальный счётчик и задание. При ошибке текст остаётся в окне, прогресс не меняется.

## Сохранность прогресса

- Не меняем домен, путь, PWA scope, имя/версию IndexedDB, список object stores, `initStore`, `seedDemoData` и операции с питомцами/монетами.
- Существующие поля Telegram в `meta` остаются нетронутыми, хотя новый интерфейс их не использует.
- Сначала проверяем сборку, ошибки отправки и загрузку существующего профиля на тестовой базе. Публикуем только после настройки реальной формы и успешной пробной отправки.
- Копию данных на настоящем телефоне можно получить только с самого телефона; локальные тесты не заменяют её.

## Настройка взрослым

Создать форму Formspree, подтвердить адрес получателя, ограничить отправку доменом `drkiray.github.io`, передать ID формы для настройки сборки. На телефоне Сони настраивать почту не нужно.
