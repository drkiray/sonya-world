# Автокопии прогресса на телефоне

После обновления игра сама создаёт первую копию существующего прогресса, затем новую копию при первом открытии после семи дней. Сохраняются последние восемь копий. Файлы находятся во внутреннем хранилище Chrome и доступны в родительских настройках игры. Если запись не удалась, игра продолжает работать, а в родительских настройках видна ошибка.

Для восстановления взрослый открывает родительские настройки, выбирает дату копии и подтверждает замену. Перед заменой игра сохраняет текущий прогресс как страховочную копию. Запись во все десять хранилищ IndexedDB проходит одной транзакцией: при ошибке она отменяется. Текущий родительский PIN сохраняется.

Кнопка «Скачать резервную копию» по-прежнему создаёт обычный JSON-файл. Теперь его можно выбрать в родительских настройках для восстановления.

**Ограничение:** внутренние копии находятся в данных сайта. Очистка данных Chrome, удаление приложения вместе с его данными или потеря телефона удалят и игровой прогресс, и эти копии. Веб-приложение не может без разрешения пользователя гарантированно сохранять видимый файл в папке «Загрузки». Для защиты от потери телефона нужна внешняя копия, которую взрослый скачает вручную, либо сервер.
